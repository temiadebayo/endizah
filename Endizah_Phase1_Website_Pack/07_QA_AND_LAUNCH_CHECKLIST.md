# 07 — QA & Launch Checklist

## Brand and content
- [ ] Correct logo used without distortion.
- [ ] Palette and typography match approved direction.
- [ ] Copy follows Endizah voice.
- [ ] Founder story and founding date verified.
- [ ] Garment details and fabric claims verified.
- [ ] All imagery approved and accurately represents the brand.
- [ ] No invented testimonials, press logos or customer counts.
- [ ] Contact details and social URLs verified.
- [ ] No placeholder content accidentally published.

## Responsive
- [ ] 360px mobile.
- [ ] 390px mobile.
- [ ] 430px mobile.
- [ ] Tablet portrait and landscape.
- [ ] Desktop and large desktop.
- [ ] No horizontal overflow.
- [ ] Navigation and mobile menu usable.
- [ ] Collection showcases readable.
- [ ] Forms usable on touch devices.

## Navigation and content
- [ ] All header and footer links work.
- [ ] All collection links resolve.
- [ ] Garment showcase routes resolve.
- [ ] CTAs lead to the correct enquiry/contact destination.
- [ ] FAQs display correctly.
- [ ] Social links verified.
- [ ] No dead ends or placeholder hrefs.

## Sanity
- [ ] Editors can update homepage content.
- [ ] Editors can update story and collection pages.
- [ ] Editors can create/edit garment showcases.
- [ ] Editors can update FAQs and contact information.
- [ ] Preview mode works.
- [ ] Draft content is not unintentionally public.
- [ ] Permissions are appropriate.

## Forms
- [ ] Required fields validated.
- [ ] Email and phone validation.
- [ ] Measurement units clear.
- [ ] Measurement-help option available.
- [ ] Privacy acknowledgement present.
- [ ] Spam protection works.
- [ ] Submission reaches approved destination.
- [ ] Customer acknowledgement works.
- [ ] Error and success states are clear.
- [ ] Enquiry is not represented as a confirmed order.

## Accessibility
- [ ] Keyboard-only navigation.
- [ ] Visible focus states.
- [ ] Semantic heading structure.
- [ ] Form labels and error associations.
- [ ] Sufficient contrast.
- [ ] Meaningful alt text.
- [ ] Reduced motion respected.
- [ ] Touch targets sufficiently large.

## SEO and performance
- [ ] Page titles and meta descriptions.
- [ ] Canonical URLs.
- [ ] Sitemap.
- [ ] Robots settings correct.
- [ ] Staging is not indexed.
- [ ] Open Graph metadata.
- [ ] Responsive image sizes.
- [ ] Hero image prioritised.
- [ ] Below-fold images lazy-loaded.
- [ ] No unnecessary third-party scripts.
- [ ] Mobile performance tested.

## Security and handover
- [ ] HTTPS active.
- [ ] CMS permissions restricted.
- [ ] Secrets stored securely.
- [ ] Form handling secure.
- [ ] Upload restrictions configured if uploads exist.
- [ ] Privacy notice approved.
- [ ] Hosting and deployment documented.
- [ ] Sanity editor guide supplied.
- [ ] Backup/rollback plan documented.
- [ ] Support and maintenance responsibilities agreed.

## Launch blockers
- Approved contact details and social URLs.
- Approved policies and privacy content.
- Custom enquiry recipient and handling process.
- Final approved photography.
- Final approved copy.
- Production domain, hosting and SSL.
- Form delivery and acknowledgement verified.

## Phase 1 scope check
- [ ] No cart.
- [ ] No checkout.
- [ ] No payment gateway.
- [ ] No inventory management.
- [ ] No order management.
- [ ] No commerce backend.

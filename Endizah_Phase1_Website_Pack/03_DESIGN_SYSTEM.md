# 03 — Endizah Digital Design System

## Creative direction
**Contemporary African fashion editorial.**

The website should feel like opening a fashion publication and discovering a confident, modern African fashion label. Balance the expressive logo with elegant typography, calm backgrounds, strong photography and disciplined layouts.

The logo is the expressive signature. The rest of the interface should give it room to breathe.

## Colour palette

| Token | Hex | Use |
|---|---|---|
| Deep Chocolate | `#3B1F0F` | Primary text, footer, dark sections |
| Bitter Chocolate | `#6B3A2A` | Buttons, highlights, active states |
| Warm Cocoa | `#C4956A` | Borders, icons, subtle accents |
| Caramel | `#D4A574` | Tags, subtle backgrounds |
| Light Nude | `#E8C9A0` | Supporting section backgrounds |
| Ivory White | `#FAF3EC` | Main canvas |

Ivory should dominate. Deep Chocolate is the primary text colour. Bitter Chocolate is the main action colour. Check text contrast; do not use light caramel tones for small body text.

## Typography
- Display/headings: Playfair Display.
- Body/UI: DM Sans.
- Use expressive editorial headlines with highly readable body text.
- Avoid too many font weights and competing display faces.
- Use responsive type scaling and restrained letter spacing.

## Photography
Original Endizah photography is a major success factor. Prioritise:
- Campaign hero.
- Women's collection imagery.
- Men's collection imagery.
- Accurate fabric close-ups.
- Garment details and fit.
- Founder/team and behind-the-scenes imagery.

Use soft directional or natural light, tactile environments, confident relaxed models and modern styling. Product imagery must accurately represent real garments. Never present generated or stock clothing images as actual Endizah inventory.

## Layout
- Generous whitespace and clear section rhythm.
- Strong editorial grid, typically 12 columns on desktop.
- Max content width around 1440px.
- Image-led collection showcases.
- Avoid excessive rounded cards, gradients, glassmorphism and dashboard UI.
- Do not overuse Ankara patterns as decoration; let real garments provide cultural expression.

## Key components
- Header with logo, navigation and mobile menu.
- Editorial hero with one primary CTA.
- Image-led collection tiles.
- Garment showcase cards with enquiry CTA.
- Brand story feature.
- Fabric feature blocks.
- Custom-order CTA.
- Social links/feed.
- Footer with contact and approved policies.

## Interaction
Use subtle image transitions and restrained reveals. Avoid scroll-jacking, long intro animations and anything that obstructs browsing. Respect reduced-motion preferences. All interactions must work without hover.

## Responsive
Design for 360px mobile first. Ensure:
- No horizontal overflow.
- Touch-friendly navigation and controls.
- Readable type and image crops.
- Forms are easy to complete.
- No sticky UI obscures content.
- Collection showcases remain visually clear.

## Accessibility
Semantic structure, keyboard navigation, visible focus, labels and errors for forms, sufficient contrast, meaningful alt text and reduced-motion support.

## Avoid
- Generic fashion templates.
- Overly decorative African motifs.
- Wedding-vendor catalogue aesthetics.
- Fake luxury gold gradients.
- Distorted or repeatedly watermarked logos.
- Stock imagery that misrepresents the brand.
